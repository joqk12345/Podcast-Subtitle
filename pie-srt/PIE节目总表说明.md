# PIE 节目总表说明

总表文件：[`PIE节目总表.csv`](PIE节目总表.csv)

## 范围

- 共 **239 条节目记录**：第1—225期、番外01—10、四次周年特别篇。
- 已映射当前目录中的 **237 个字幕文件**。
- 第155、156期在节目目录中存在，但当前目录没有对应字幕，文件名标为“（本地缺失）”。
- CSV 使用 UTF-8 BOM 编码，可直接用 Excel 打开。

## 字段与来源

| 字段          | 整理方法                                                                                   |
| ----------- | -------------------------------------------------------------------------------------- |
| 期号、日期、标题、主题 | 依据节目公开 RSS（`https://proxy.wavpub.com/pie.xml`，读取日期：2026-08-11）；日期为 RSS 发布日期，不一定等于录制日期。 |
| 主播          | 常规阵容记为“李俊、王老师、老庄”；第86期依据标题改为“王老师、老庄”。其余逐期出席情况尚待回听核校。                                   |
| 嘉宾          | 只录入 RSS 标题或简介明确提到的嘉宾；空白表示 RSS 未明确注明，不等于确定无嘉宾。周年活动统一记“听友”。                              |
| 主题          | 取 RSS 简介的首个有效段落，保留节目方原有概述。                                                             |
| 关键词         | 根据标题和主题按受控分类词表自动标注，最多六项，适合初步筛选，尚需人工复核。                                                 |
| 文件名         | 带期号文件直接对应；早期随机文件名依据 SRT 末时间与 RSS 音频时长进行一对一映射。                                          |

## 映射核验

早期随机文件名的时长匹配中，大多数误差低于 4 秒；少数约为 10—14 秒，应是片尾或字幕截断差异。全部候选均形成唯一、顺序合理的对应关系。已确认本地真正缺少的是：

- 第155期《后互联网时代的黑产》
- 第156期《AOSP咋回事》

正式研究或发表前，建议重点人工复核“主播、嘉宾、关键词”三列，并以节目音频及官方页面为准。
